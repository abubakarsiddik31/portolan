`map build` records the backend's endpoints. While it crawls, the API calls each page makes are grouped into endpoints (method and path with ids as `{id}`, query parameters, body and response keys, statuses, the pages that call them, whether they were authenticated) and written to `endpoints.json`. `map status` shows how many an op's `http` impl reaches and how many writes no op reaches, so a part of the backend no button exposed is a visible gap.
